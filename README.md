# Riesgo País en vivo (réplica)

Réplica propia del riesgo país de J.P. Morgan (EMBI Global Diversified, Argentina) con datos públicos:
precios de los seis Globales ley Nueva York (BYMA vía data912, en dólar cable), curva del Tesoro de EE.UU.
y serie oficial de ArgentinaDatos. Se actualiza cada 15 minutos durante la rueda con GitHub Actions.

Página: https://fabriciojoel.github.io/riesgo-pais/ · Datos: `data/riesgo_pais.json`

Estimación con fines educativos; no es el índice de J.P. Morgan ni recomendación de inversión.
